# Mã Python

- `03_torch_garch_baseline.py`: bản đầy đủ tương đương notebook chính. Từ thư mục gốc, chạy `python src/03_torch_garch_baseline.py`.
- `portfolio_baseline.py`: hàm minimum variance, backtest và chỉ số hiệu quả danh mục.
- `torch_garch_extension.py`: MLP, GARCH, các khoảng dự báo và danh mục so sánh; là nguồn để builder nhúng vào bản chính, không chạy riêng từ đầu.

Muốn đọc từng bước cùng output, dùng [notebook chính](../03_torch_garch_baseline.ipynb).
